考研英语词组记忆器 PWA 安装版
============================

一、上传到GitHub
----------------
1. 解压本压缩包。
2. 打开仓库：xjflovelyx-sudo/kaoyan-phrase-trainer
3. 点击 Add file → Upload files。
4. 上传解压后的全部文件，不要只上传ZIP。至少包括：
   index.html
   manifest.webmanifest
   service-worker.js
   icon-64.png
   icon-180.png
   icon-192.png
   icon-512.png
   完整词组数据_2021-2026_补全选择题版.json
   big_essay_data_5_confirmed.json
   small_essay_data_13_exam_template.json
   small_essay_module.css
   small_essay_module.js
5. 点击 Commit changes。
6. 等待 Actions 出现绿色对勾。
7. Windows 按 Ctrl+F5；手机和平板关闭旧标签后重新打开。

二、Windows安装
---------------
1. 用 Edge 或 Chrome 打开网站。
2. 点击网页顶部的“安装应用”。
3. 点击“安装”。
4. 以后可以从桌面、开始菜单或任务栏打开。

若网页没有显示安装按钮：
- 查看地址栏右侧是否有安装图标；
- 或打开浏览器菜单，选择“安装此网站作为应用”。

三、Android安装
---------------
1. 用 Chrome 打开网站。
2. 点击网页中的“安装应用”。
3. 根据提示完成安装。

若没有按钮：
Chrome右上角菜单 → 安装应用／添加到主屏幕。

四、iPhone或iPad安装
-------------------
1. 使用 Safari 打开网站。
2. 点击“共享”。
3. 选择“添加到主屏幕”。
4. 点击“添加”。

五、数据说明
------------
- 安装版继续使用现有Supabase账号。
- 原有词组、错词、复习进度不会丢失。
- Windows、手机、平板仍然可以同步。
- 断网时可使用本地数据；恢复网络后点击“立即同步”。

六、更新
--------
以后更新GitHub文件后，保持联网并重新打开应用即可逐步获取新版。
如仍显示旧版：
- 先确认网页左上角标题显示“V28”。
- Windows：退出已安装应用，在浏览器打开网站并按 Ctrl+F5。
- Chrome/Edge仍旧时：网站设置 → 清除该网站的数据，然后重新打开。
- 手机：关闭应用后重新打开；仍未更新时清除该网站缓存后重新添加到主屏幕。
