二、选择题功能
--------------
1. 全部2714条词组均可进入选择题。
2. 可按年份、类别、个人标记和题数筛选。
3. 支持中文选英文、英文选中文和中英混合。
4. “同义替换”类别会专门考查两个表达是否同义。
5. 答对和答错后都停留在当前题，不会自动跳转。
6. 答错后显示：正确答案、所选选项含义、年份、真题部分、熟词新义提示、同义表达和个人备注。
7. 错题自动计入错词本和间隔复习。
8. 本轮结束后可只重做错题。

三、上传方法
------------
1. 解压“考研英语词组记忆器_PWA真题补全选择题版.zip”。
2. 打开：https://github.com/xjflovelyx-sudo/kaoyan-phrase-trainer
3. Add file → Upload files。
4. 上传压缩包内全部文件，覆盖同名文件。
5. Commit message：Complete 2021-2026 papers and add MCQ quiz
6. 等待Actions绿色对勾。
7. 浏览器按Ctrl+F5。
8. 电脑软件、手机和平板应用完全关闭后重新打开两次。

四、数据安全
------------
- 新词组会根据年份、部分和英文结构自动合并到旧进度中。
- 原有账号、复习记录、错词、自定义标记、标记分组和个人备注会保留。
- 4条低价值孤立单词卡已从内置词库移除；旧云端中的对应卡也会自动过滤。
